★ I2C Shared Bus — BMP280 and OLED both share GPIO 21 (SDA) and GPIO 22 (SCL). Wire them in parallel — same two pins, two sensors connected together. This works because they have different I2C addresses (BMP280 = 0x76, OLED = 0x3C).
⚡ Power — Use 3.3V only. Never connect sensors to 5V — ESP32 GPIO is not 5V tolerant.
🌡 DHT22 Pull-up — Add a 10kΩ resistor between DATA and 3.3V for stable readings. Some modules have it built in.
📡 Rain / LDR — Use ADC1 pins only (GPIO 32–39). ADC2 conflicts with WiFi on ESP32.
🔄 BMP280 Address — If BMP280 not found, try 0x77 instead of 0x76 in the code (SDO pin HIGH = 0x77).
